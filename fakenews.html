System Methodology & Integration

KhabarCheck utilizes a hybrid approach for detecting misinformation, supporting both Live LLM Inference via OpenRouter and a fallback Client-Side Heuristic Engine.

Primary: OpenRouter LLM Integration

When an API key is provided, the platform communicates directly with cloud-based Large Language Models via OpenRouter. The text is passed through a strict system prompt that forces the LLM to act as a classification engine. It evaluates semantic truthfulness, tone, and formatting, returning a structured JSON response containing the confidence score and feature breakdown.

Fallback: Client-Side Heuristics

If no API key is present, the engine instantly falls back to analyzing the input text locally in real-time to extract specific linguistic markers highly correlated with misinformation:

  • Image OCR (Simulated): When a news screenshot or photo is uploaded, the system simulates extracting text via Optical Character Recognition to analyze embedded meme text.
  • Subjectivity / Polarity (Simulated): Looks for strong opinionated phrasing versus neutral, objective reporting language.

    • Scoring Algorithm

    The text starts with a baseline "fake probability" based on its length. Each detected feature adds a weighted penalty to the score. The final score is clamped between 0% and 100%. If the score exceeds 60%, it is flagged as Fake/Suspicious.
